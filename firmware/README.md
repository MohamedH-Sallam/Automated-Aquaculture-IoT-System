# Firmware source status

The project report documents Arduino UNO R3 control and includes descriptions of the pH, temperature, pump, motor, and Bluetooth functions. It does not provide the complete firmware source as a repository ready code listing.

No firmware has been invented or represented as the original program in this directory. The documented control sequence is in [`../docs/control_logic.md`](../docs/control_logic.md).

To make the firmware reproducible, the original Arduino sketch, library versions, pin mapping, calibration constants, sampling interval, motor step counts, and fault handling behavior must be recovered from the project files or rebuilt and tested against the physical circuit.
